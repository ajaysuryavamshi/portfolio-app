# Portfolio Sitemap - Senior SDET

## 1. Home Page (Landing)
- **Hero Section**: 
    - High-impact headline (Value Prop).
    - Sub-headline focusing on Quality Engineering & ROI.
    - Primary CTA: "View Case Studies" / "Contact Me".
- **Core Pillars**: 
    - Three cards highlighting: Framework Architecture, CI/CD Optimization, and Performance Engineering.
- **Quick Skill Summary**: 
    - Icon-based grid of top-tier tools (Java, Playwright, Jenkins, etc.).
- **Testimonials/Endorsements**: 
    - Short quotes from peers or managers.

## 2. Case Studies (Projects)
- **Project Listing Page**: 
    - Grid of projects with thumbnails, titles, and a one-sentence "Impact Statement".
- **Project Detail Page (Dynamic Template)**:
    - **Situation**: The business/technical problem.
    - **Task**: The specific goal (e.g., "Reduce regression time by 50%").
    - **Action**: Technical deep dive (Architecture, tools used, design patterns).
    - **Result**: Quantifiable metrics (The "Senior" part).
    - **Tech Stack**: List of tools used for this specific project.
